1.1　三种落地方式

每张单据先判定落地方式。判定规则：字段平铺、无跨单据取数和计算的审批单走 P1；有明细联动、自动取数、计算或平板录入的单据走 P2；不需要审批（或只做事后审核）的录入与台账走 P3。

P1 OA 原生流程

  • 表单、流程在通达流程中心用低代码配置，顺翼管理员可自行调整节点和审批人
  • 选文件、选样品等字段用「QMS 数据选择控件」（宏控件调 QMS 接口）
  • 流程结束或到指定节点时，流程插件回调 QMS 执行业务动作（开放阅读权限、升版、放行打印份数）
  • RUN_ID 写回 QMS 业务表，双向可查

P2 QMS 单据页 + OA 审批

  • 单据在 QMS 页面编辑（明细网格、自动带出、计算、校验三层）
  • 审批节点建为 OA「外部流程」，待办出现在 OA 审批中心，点开即 QMS 办理页
  • QMS 校验通过才允许转交；退回到指定已办节点由 QMS 判定后调 /works/back
  • 节点字段权限由 QMS 控制（后端再校验）

P3 QMS 功能页

  • 检验录入、SPC、项目甘特图、样品台账、留样柜、报表
  • 挂在 OA 菜单（应用中心 / 自定义菜单），从 OA 进入免登
  • 事后审核类（检验单）在页面内完成，不进 OA 流程，避免卡 ERP 周转
  • 提醒类消息仍走 OA 消息中心

3.1　文档管理

以受控文件库为核心，6 个流程都围绕库内文件运转。上线前批量导入现行受控文件约 1,400 条（程序文件约 33、作业指导书 386、包装规范 750、表单 223，另三级文件分类页 468 条去重后并入）。

文件状态

DRAFTING起草中→ TRIAL试产版→ RELEASED受控正式版→ OBSOLETE作废

新文件经会签或更改申请核准后进入受控正式版（图面、控制计划在 ECN 试产阶段先为试产版）。同一文件编号同时只有一个受控正式版；升版时旧版转作废并触发回收。版本、状态、发布日期只能由流程回调改写，导入初始化除外。

六个流程

申请人选受控正式版，可多份→部门主管→文控开放阅读权限→到期自动收回写实际归还日期

① 借阅 P1　电子借阅只给在线阅览权（禁止下载、打印）；纸质借阅由文控确认归还。到期前 1 天提醒，逾期抄送文控。

起草人新制定 / 修订，上传附件→并行会签指定部门，手写签名→审核→批准→自动归档入库 + 写制修订记录

② 文件会签 P1　收件日期 = 到达会签节点时间，会签日期 = 提交时间；任一部门不同意退回起草人。归档时插件回调 QMS：文件状态置受控正式版、版本 +1、写 SYFM0310 一行、按发放范围生成发放记录。

申请者选库内文件，上传变更后文件→变更部门意见→会签申请人指定，最多 5 部门→审核→核准→换版版本 +1，旧版作废，发放与回收

③ 更改申请 P1　ECN「文件更新」事项自动生成更改申请草稿并带出 ECN 单号；全部关联文件换版后 ECN 才能关闭。会签部门超过 5 个时表单校验拦截。

文控登记发放类别、编号、版次、首次与否→接收人签收电子回签 / 纸质签名→非首次?→回收旧版回收份数 = 发放份数才完成

④ 发放登记 P3　图面规则：电子档发物控、品质、采购，纸质档发生产（生计部、物控）；变更回收时电子档由工程回收（系统自动收回权限），纸质档由接收部门交回。

申请人→申请单位主管→文控中心→责任单位

⑤ 补发 P1　申请张数同时作为受控打印份数上限；文控通过后生成纸质发放行（分发编号新增）。

申请人文件、份数、使用地点→部门主管→文控→QMS 打印台放行按份数，逐份带分发编号
